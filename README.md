# rjrs-torment-and-legacy
Prebuilt map of the PF2e one-shot Torment and Legacy (campaign book and details not included). I hope you like it. :)
### Info
Click twice on orange buttons to activate it.
Blue stairs represent a change in elevation.
Tiles placed over the map are highly translucent, so as not to clutter the DM's view. None of them are visible to players.
