# RJR's Torment and Legacy
RJR's Torment and Legacy is a prebuilt map for Foundry VTT v13. Book and campaign details are NOT included. You must download the adventure book from Paizo separately to play this one-shot.

I hope you like it. :)
### Info
Orange buttons can be clicked twice to run its effect.

Blue stairs represent a change in elevation.

Tiles placed over the map are highly translucent, so as not to clutter the DM's view. None of them are visible to players.

You can change all assets used by this module with ease. To do so, you can go to the path "Data/modules/rjrs-torment-and-legacy/assets/" and replace any of the assets for a matching substitute with the exact same file name and format.
